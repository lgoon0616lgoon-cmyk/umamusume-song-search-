ウマ娘 歌唱楽曲検索サイト（固定URL・Excel更新対応）

【公開機能】
・ウマ娘画像をPCで横5列表示
・ウマ娘画像をクリック → 歌唱楽曲を画像付きで表示
・楽曲画像をクリック → 歌唱ウマ娘を画像付きで表示
・ウマ娘名／楽曲名の検索
・スマホ対応（画面幅により3列/2列）

【更新機能】
・/admin を開く
・管理パスワード＋新しい .xlsx を選択
・更新ボタンを押す
・サイトURLは変更されない
・Excel内のセル画像を再抽出し、行と名前を再対応付け
・更新前のExcelは backups フォルダへ保存

【重要】
本番公開時は環境変数 ADMIN_PASSWORD を必ず設定してください。
また、更新ファイルを保持するため、永続ディスク/永続ストレージのあるNode.jsホスティングを使用してください。

【ローカル起動（Node.js導入済みの場合）】
1. npm install
2. Windows PowerShell: $env:ADMIN_PASSWORD="任意のパスワード"
3. npm start
4. http://localhost:3000
5. 管理画面 http://localhost:3000/admin

【公開】
Docker対応です。VPS、Railway、Render等のNode.js対応サービスへ配置できます。
ただしサービスによって永続ディスクの有無・料金体系が異なるため、公開先に合わせて設定してください。
